# Тема UI — спокойная индиго/бирюза

**Решение.** Визуальный стиль — спокойная «учёба»: индиго (primary) + бирюза/teal (accent), нейтральные фоны, мягкие акценты. Поддержка dark+light (`darkMode: 'class'`). Не яркий фиолетово-розовый бренд ToonyGamy.

**Почему.** Приложение для долгих учебных сессий — нужен спокойный, читаемый, нефонящий интерфейс. Владелец выбрал этот вариант.

**Токены (стартовые, Tailwind/CSS-vars; уточняются на Phase 3).**
- primary: индиго (~`#4f46e5` / hsl 243 75% 59%), accent: teal (~`#0d9488`).
- Фоны нейтральные (slate); немецкий контент визуально маркируется (бейдж/моноширинный/жирный + перевод на русском).
- Шрифты: Inter (body), Plus Jakarta Sans (shell ассистента). WCAG 2.1 AA контраст.
