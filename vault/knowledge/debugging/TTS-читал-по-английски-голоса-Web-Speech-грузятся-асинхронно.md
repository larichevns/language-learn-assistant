# TTS читал немецкие слова по-английски - голоса Web Speech грузятся асинхронно

**Симптом.** Кнопка озвучки (`SpeakButton`) читала немецкие слова (например «die Rechnung») английским голосом - фонетика английская.

**Корень.** `lang='de-DE'` на `SpeechSynthesisUtterance` **недостаточно** - движок берёт голос из `utter.voice`, а если он не задан, использует **системный дефолт** (на этой машине - `Daniel [en-GB]`). Код пытался выбрать немецкий голос через `speechSynthesis.getVoices().find(...)`, но в Chrome **`getVoices()` грузится асинхронно** и на первом клике после загрузки страницы возвращает `[]` → немецкий голос не найден → тихий фолбэк на английский дефолт. Немецкие голоса в системе есть (`Anna [de-DE]` и ещё 8), проблема только в тайминге.

**Фикс** (`components/ui/speak-button.tsx`): прогреваем и кэшируем голоса на маунте и по событию `voiceschanged`; выбираем **именно `de-DE`** (затем любой `de`); если на момент клика голоса ещё не готовы - ждём `voiceschanged` (фолбэк-таймаут 600 мс) и только потом говорим, **никогда не падая на дефолт**.

**Проверка (live).** Перехватил `speechSynthesis.speak`, кликнул реальную кнопку на `/vocabulary` → в utterance `voice = {name:"Anna", lang:"de-DE"}`, `lang:"de-DE"` для «der Bahnhof». Раньше при пустом `getVoices()` тут был бы `Daniel [en-GB]`.

**Урок.** Любой Web Speech TTS: всегда задавай явный `voice`, а не только `lang`, и учитывай асинхронную загрузку `getVoices()` (грей на маунте + слушай `voiceschanged`).
